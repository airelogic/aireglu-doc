Fax Task (Deprecated) ​

The Fax task is no longer supported via the editor

The Fax task sends the contents of a PDF document to a fax machine or other fax receiving service. The PDF may be from the input data, an external service (via HTTP Request task), or the PDF task.

Settings ​

  • From - your name.
  • To - the recipient's name.
  • Number - the recipient's fax number.
  • PDF Attachment - the base64 PDF data. You can insert this from the Context Data panel.
  • Optionally, a subject line.
  • Optionally, descriptive text.
